## Layout

| Path | What |
|---|---|
| `crates/{{name}}-core` | the domain – types and rules, no I/O |
| `crates/{{name}}-store` | where the data lives (provisional: in memory – OPEN: SQLite for local-first, PostgreSQL for servers) |
| `crates/{{name}}-app` | the workspace: every command and query; the **only** layer the interfaces use |
| `crates/{{name}}-api` | HTTP/JSON with axum, described in OpenAPI by utoipa; serves the embedded web app |
| `crates/{{name}}-tui` | the terminal interface (ratatui) – keyboard and mouse |
| `crates/{{name}}` | the command line: `serve`, `tui`, `openapi` |
| `web/` | the web app: Vite, Svelte 5, TypeScript; types from `api/openapi.json` (openapi-typescript, openapi-fetch) |
| `api/openapi.json` | generated by `{{name}} openapi`; CI checks it matches the code |
| `docs/` | {{docs_domain}} – Jekyll, Just the Docs, published by GitHub Actions |
{{/rust_app}}

## Principles

- **Everything included:** one edition, every feature free; no paid tiers, licence keys or unlocks.
- **No telemetry.** Only connections that are technically needed or that users start themselves.
{{#rust_app}}
- **One core, many interfaces:** TUI, API and CLI go through `{{name}}-app`; the web app and apps only through the
  API, which is also the licence boundary for apps under other licences.
{{/rust_app}}

## Rules

- English in code, docs and commits; commits signed off (`git commit -s`).
- No personal data in tracked files (names, paths like `/Users/…`, hostnames, keys).
- Claims need a source; unverified statements are marked **OPEN**.
- No externally loaded fonts or scripts in anything web-based.
{{#rust_app}}
- Dependencies exact and at least 14 days old (CONTRIBUTING.md); Rust edition 2024, the toolchain in
  `rust-toolchain.toml`; TypeScript 6 until Svelte supports 7, Node 26, pnpm.
- After changing the API: `cargo run -q -- openapi > api/openapi.json` and `pnpm --dir web api`.
{{/rust_app}}
