# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub – the repository's
*Security* tab, *Report a vulnerability* – or by mail to [support@falkoss.org](mailto:support@falkoss.org).

Say what is affected (version or commit, component), how to reproduce it, and what an attacker gains. We confirm the
report within a week, keep you informed, and credit you in the advisory unless you prefer not to be named. Fixes are
released as soon as they are ready; the advisory follows once users have had a chance to update.

## Supported versions

Before 1.0, only the latest release gets security fixes.
